# RAM - Interactive Memory Lab

[English](README.md) · [변경 이력](CHANGELOG.md) · [과학 모델과 한계](docs/SCIENTIFIC-MODEL.md) · [근거 자료](SOURCES.md) · [검증 결과](docs/QA.md)

SRAM·DRAM·HBM·HBF·3D NAND의 **구조, 회로, 동작 단계, 저장 데이터**를 같은 시뮬레이터 상태로 연결해 탐색하는 웹앱입니다. [JTech-CO/RAM](https://github.com/JTech-CO/RAM)의 `a2c3cbd63b7058c0853e7197e22d660017d0087c` 리비전을 참고했습니다. 이 패키지는 기존 저장소를 변경하지 않습니다.

## 실행

**`RAM-Lab-Standalone.html`을 브라우저에서 여세요.** 실행 코드가 모두 포함되어 CDN, 로그인, API 키, 패키지 설치가 필요 없습니다. 폴더 버전은 `index.html`과 `css/`, `js/`, `assets/`의 상대 위치를 유지합니다. 개발 서버도 포함했습니다.

```sh
npm start
# http://127.0.0.1:5173
```

Node.js 18 이상은 개발 명령에만 필요하며, HTML을 여는 데에는 필요하지 않습니다. 앱·서버·빌드·모델 테스트에는 npm 의존성이 없습니다.

## v1.1 수정 사항

**글자와 반응형 배치.** 기존의 6~9px 소형 글자를 정리하고 UI 최소 크기를 12px로 올렸습니다. 본문과 상세 설명은 주로 15px입니다. 화면이 좁아져도 글자를 줄이지 않고 조작부를 줄바꿈하고 패널을 세로로 배치합니다. 셀 배열과 비교표는 패널 안에서만 가로 스크롤합니다.

**KR / EN 전환.** 상단과 설명 창에서 언어를 바꿉니다. UI, 원리 설명, 회로, 도움말, 오류 메시지와 출처 설명이 함께 바뀝니다. 주소·입력값·저장 데이터·재생 단계·회로 확대 위치는 유지됩니다. 언어 선택만 브라우저의 `localStorage`에 저장하며, 저장이 제한된 환경에서도 현재 세션의 언어 전환은 동작합니다.

**간결한 요약과 펼치는 상세 설명.** 순서도에는 짧은 단계 이름만 표시합니다. 수식과 데이터·모델 범위 요약은 바로 보이고, 구체적인 설명은 ‘자세히 보기’에서 펼칩니다. 새 모바일 세션에서는 단계 상세 설명과 3D 주석을 접거나 끈 상태로 시작합니다. 기능을 삭제한 것이 아니라 모델이 가려지지 않도록 기본 표시만 달리했습니다.

**회로 확대.** + / - 버튼, 휠, 두 손가락 핀치로 확대하고 드래그로 이동합니다. 단계 이동과 언어 전환으로 시점이 초기화되지 않으며, 메모리 종류별 회로 시점도 현재 세션에서 보존합니다. ‘전체 보기’는 전체 회로를 맞추고, ‘기본 배율’은 읽기 좋은 크기로 되돌립니다. 모바일의 기본 배율은 100%이므로 드래그해서 나머지를 봅니다. 직접 축소하거나 전체 보기를 선택하면 회로 속 글자도 작아질 수 있지만 툴바 글자는 축소되지 않습니다.

## 조작과 실험

| 화면 / 포커스 | 조작 |
|---|---|
| 3D | 드래그 회전, Shift + 드래그 이동, 휠·핀치 확대, R 초기화 |
| 회로 | 드래그 이동, 휠·핀치·+ / - 확대, 방향키 이동, F 전체 보기, 0 / R 기본 배율 |
| 입력창 이외의 일반 UI | Space 재생·정지, 방향키 단계 이동 |

회로에 포커스가 있을 때만 방향키가 회로 이동에 우선 사용됩니다. 전체 화면 API가 없는 환경에서는 확장 보기로 전환합니다.

DRAM 읽기를 한 단계씩 진행하면 프리차지·전하 공유·감지·복원을 확인할 수 있습니다. 같은 행 재접근, SRAM의 전원 차단, DRAM 예시 누설 실험도 제공합니다. NAND/HBF에서는 TLC로 바꾸고 `한`을 UTF-8로 변환하면 `ED959C`가 됩니다. 프로그램을 끝까지 실행한 뒤 결과를 확인하세요. 이미 프로그램한 페이지 표본은 다시 쓰기가 차단되며, 블록 소거는 해당 블록 전체에 적용됩니다. HBM에서는 셀 접근과 병렬 데이터 전송을 구분해 관찰합니다.

PNG는 3D 장면만 저장합니다. JSON은 현재 상태를 진단용으로 내보내며 다시 불러오는 기능은 없습니다.

## 수정·검증·정적 배포

```sh
npm test
npm run build:portable
npm run test:browser
npm run test:ui
npm run test:layouts
```

브라우저 테스트는 선택 사항으로 Python·Playwright·Chromium이 필요합니다. Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다. 앱 실행에는 이 도구들이 필요하지 않습니다. 검증 결과와 한계는 [QA 문서](docs/QA.md)를 참고하세요.

정적 호스팅에는 `index.html`, `css/`, `js/`, `assets/`를 함께 배치합니다. 소스를 바꾼 뒤에는 단일 HTML을 다시 빌드합니다. 공개 URL 배포나 기존 GitHub 저장소의 수정은 이 파일 패키지에 포함되지 않습니다.

## 모델 범위와 데이터

대표 구조와 연결 관계에 기반한 **교육용 모델이며 제조사 치수로 보정한 TCAD/SPICE 시뮬레이터가 아닙니다.** 색상·치수·층수·경로 수·시간축은 설명용입니다. HBF는 공개 정보 기반 개념 모델이며 상용 제품 사양을 보증하지 않습니다. 제조 공정과 식각 장비는 다루지 않습니다. 이번 수정에서는 시뮬레이터 커널과 3D 소자 형상을 변경하지 않았습니다.

WebGL 2를 우선 사용하며, GPU 컨텍스트가 없으면 깊이 버퍼가 있는 Canvas 소프트웨어 3D 렌더러로 전환합니다. 회로와 상태 시뮬레이션은 렌더러와 독립적입니다.

외부 전송·분석 도구·런타임 CDN은 없습니다. 자동 저장 대상은 언어 선택뿐입니다. 브라우저 새로고침 시 메모리 표본은 초기화되며, 앱 안의 비휘발성 실험은 브라우저를 닫아도 데이터가 보존된다는 의미가 아닙니다.
