# 과학 모델 · 구현 범위와 단순화

검토 기준: 2026-09-10. 근거: [SOURCES.md](../SOURCES.md). 참고 저장소 리비전: `a2c3cbd63b7058c0853e7197e22d660017d0087c`.

## 1. 무엇을 모델링하는가

이 앱은 저장 상태가 생기는 원리, 주소 선택, 읽기 판정, 쓰기 상태 전이, 복원·리프레시 또는 소거의 필요성을 연결하는 교육용 모델이다. 형상은 절연층·전극·게이트·채널·배선·다이를 구분한 대표 구조이며 제품별 현미경 단면이나 GDS를 복제하지 않는다.

모든 메모리를 같은 종류의 RAM으로 취급하지 않는다. SRAM은 능동 래치, DRAM과 HBM은 커패시터 기반 휘발성 저장, NAND와 HBF는 전하 저장층에 의한 비휘발성 저장으로 구분한다. HBM/HBF는 셀 원리와 패키지·인터페이스 계층을 함께 봐야 하며, 서로 독립적인 다섯 종류의 셀 물질을 의미하지 않는다.

공정 순서, 식각 장비, 웨이퍼 생산, 수율 예측, 시장 정보는 구현하지 않았다.

## 2. SRAM

대표적인 6T 구성을 사용한다. 두 CMOS 인버터의 입력과 출력을 교차 결합하고, 같은 WL로 제어하는 두 액세스 NMOS를 BL/BL̅에 연결한다. Q와 Q̅은 두 비트가 아니라 한 비트의 상보 표현이다.

읽기는 BL/BL̅ 프리차지 → WL 활성화 → 한쪽 BL의 미소 방전 → 차동 판정 → 셀 분리로 표현한다. 쓰기는 상보 BL 구동으로 래치 상태를 바꾼다. 원래 상태를 유지한 채 읽는 정상 동작만 모델링하며 read disturb·소자 크기 비율·SNM·실제 I–V 특성은 계산하지 않는다. BL의 0.12 V 변화와 VDD=1 V는 설명용이다.

전원 OFF의 X는 데이터 유효성 보장 종료를 뜻한다. 실제 물리 노드가 즉시 무전하 상태가 되는지, 얼마 동안 잔류하는지 계산한 결과가 아니다.

## 3. DRAM

대표 1T1C와 원통형 커패시터를 사용한다. 저장 전극, 고유전율 절연막, 공통 플레이트, 저장 노드 컨택, 접근 MOS, 매몰 WL, BL 및 센스 앰프를 구분한다. 선택 셀을 확대했으므로 주변 셀 크기와 비례하지 않는다.

### 전하 공유

예시 상수는 `VDD = 1 V`, `Vplate = 0.5 V`, `Cc:Cb = 1:10`이다. 이 비는 특정 제품의 커패시턴스가 아니다.

```text
Vshared = (Cc × Vcell + Cb × Vprecharge) / (Cc + Cb)
ΔVBL    = Cc / (Cc + Cb) × (Vcell − VDD/2)
```

Vcell=1 V이면 공유 후 BL은 약 0.54545 V, Vcell=0 V이면 약 0.45455 V이다. 블록도의 전하 광점은 실제 전자 수나 전하 부호를 계수하지 않는다. 공통 플레이트가 0.5 V이므로 “0은 전하가 전혀 없음”으로 해석해서는 안 된다.

감지와 복원은 실제로 시간상 겹칠 수 있다. 앱은 설명을 위해 둘을 분리하고, 센싱 중 셀 전압은 공유 값과 복원 목표 사이의 중간 상태로 표시한다. 전하 공유의 순간 상태는 시각적 상태로 계산하고, 저장된 논리 비트와 누설 전압은 별도 상태로 보관한다. 연속시간 회로 적분기가 아니다.

읽기 완료 후 열린 행을 유지한다. 같은 행 읽기는 행 버퍼를 사용하는 ROW HIT 경로가 되고, 다른 행 접근은 다시 프리차지와 ACT를 거친다. 이 표본은 8비트 워드가 한 행의 전체를 대표한다. 실물 DRAM 행은 훨씬 크며, 바이트 쓰기 마스크나 실제 주소 인터리빙은 구현하지 않는다.

### 누설과 리프레시

시간 버튼은 교육용 가상 시간만 변경한다. 기본 자동 리프레시는 아는 비트를 정확히 유지하는 이상적인 스케줄러로 추상화한다. 껐을 때는 다음 예시식을 적용한다.

```text
V(t) = 0.5 + (V₀ − 0.5) × exp(−t / 40 ms)
|V − 0.5| < 0.035 V → X
```

τ=40 ms 및 판정 마진은 실측 장치 리텐션을 의미하지 않는다. 전압이 모두 0.5 V로 수렴한다는 가정 역시 실제 누설 경로 전체를 대표하지 않는다. 온도·셀별 분포·가변 리텐션·Row Hammer를 계산하지 않는다. REF 실험은 선택 행 한 개를 대표로 감지·복원하며, 실제 장치의 내부 리프레시 주소 카운터를 구현하지 않는다. X가 된 정보는 리프레시로 회복할 수 없다.

## 4. HBM

8개의 DRAM 다이, 베이스 다이, 대표 TSV, 인터포저와 가속기를 보여준다. 8단은 구조 설명을 위한 수이며, 상용 세대·용량·핀 배치를 재현하지 않는다. 화면의 8개 뱅크, 8개 다이, 8개 전송 경로는 독립적인 교육 축으로 서로 1:1 대응하지 않는다.

읽기는 DRAM 접근 후 수직 연결과 인터포저를 거쳐 가속기로 나간다. 쓰기는 반대로 가속기 → 인터포저 → 수직 연결 → 셀 구동 순서이다. 행의 기존 상태를 감지·복원한 뒤 새 워드를 쓴다. HBM 실험은 매 요청 시작 시 이전 행을 닫는 예시 정책이며 실제 컨트롤러의 open-page 정책, 명령 큐, JEDEC 타이밍을 계산하지 않는다.

`1024 bit × 6.4 Gbit/s/pin ÷ 8 = 819.2 GB/s`는 단위 관계를 설명하는 산술 예제다. 현재 제품 사양이나 화면의 8개 경로에서 측정한 처리량이 아니다. 레인 선택은 대표 활성 경로의 수만 바꾸며, 그 수로 실효 대역폭·메모리 지연을 예측하지 않는다.

## 5. NAND와 다중 레벨 정보

대표적인 CTF 기반 수직 스트링이다. 실리콘 채널, 터널 절연막, 전하 트랩, 차단 절연막, 선택·비선택 WL, 스트링 선택 게이트, 공통 소스와 페이지 버퍼를 구분한다. 모든 NAND가 CTF를 쓰는 것은 아니다.

실험 배열은 8 WL × 8 스트링이다. SLC·MLC·TLC·QLC의 정보량은 셀당 1·2·3·4비트이고 상태 수는 `2^bpc`이다. 전하 상태가 높은 순서와 논리 비트의 수치 순서는 같지 않다. 예시 Gray 매핑으로 인접한 문턱 상태의 코드를 구성한다.

```text
gray(level) = level XOR (level >> 1)
symbol      = ((1 << bpc) − 1) XOR gray(level)
Vt(level)   = (level + 0.5) / (1 << bpc)
```

E의 모든 비트가 1인 예시를 사용한다. Gaussian 모양의 분포는 판정 구간을 설명하는 그림이며 실제 측정 통계가 아니다. 정규화 Vt 값은 실물 소자의 V 단위 전압이 아니다.

Vref 슬라이더는 하나의 비교기만 관찰한다. 비선택 셀이 통과 조건을 만족한다고 가정하고 `Vref >= Vt`일 때 선택 셀의 도통 가능성을 표시한다. 완전한 데이터 읽기는 모든 이상적인 경계 `k/2^bpc`를 비교하여 상태를 판정하고 Gray 매핑으로 비트를 복원한다. 사용자가 슬라이더 하나를 움직였다고 전체 TLC 값이 달라지는 것은 아니다.

### 페이지와 프로그램의 해석

MLC 이상에서는 같은 WL의 셀 상태가 여러 논리 페이지의 정보를 표현한다. 따라서 이 앱의 8개 셀 창은 실물 논리 페이지 한 개와 같지 않다. 프로그램 실험은 그 셀 상태들을 한 번에 목표 구간으로 옮기는 축약 모델이다. 실제 다중 패스 프로그램, 페이지 순서, 부분 페이지 제한, 프로그램 억제 전압은 구현하지 않는다.

ISPP 펄스는 목표 방향으로 Vt가 이동하는 중간 상태를 보여주고 검증 후 최종 상태를 커밋한다. 일반적인 장치 제약을 드러내기 위해 이 앱은 동일 표본 행의 재프로그램을 금지한다. 블록 소거는 선택 블록의 모든 8개 WL을 E로 바꾼다. 이 정책이 모든 상용 NAND의 부분 페이지 규칙과 같다는 뜻은 아니다.

ECC·FTL·가비지 컬렉션·마모 분산은 설명상 위치만 제시하며 실행하지 않는다. 소거 카운터가 증가해도 수명 한계나 불량을 확률적으로 만들어내지 않는다.

## 6. HBF

공개 설명에서 확인되는 NAND 기반 저장, 병렬 배열 접근, 버퍼·제어 경로와 가속기 인접 전송을 개념적으로 결합한다. HBF를 HBM의 동일 소켓 대체물이나 DRAM식 임의 바이트 덮어쓰기로 표현하지 않는다.

이 앱의 HBF 셀 포맷 선택과 프로그램·소거 실험은 공유 NAND 교육 커널의 기능이다. 특정 HBF 제품이 기본 TLC이거나 모든 SLC/MLC/TLC/QLC 모드를 제공한다는 주장이 아니다. 내부 배선, 정확한 서브어레이 수, 호스트 프로토콜, 인터페이스 입도, 보존 관리 주기, 내구성·지연 수치는 모델에 넣지 않았다. 실제 호스트가 직접 물리 블록 소거를 지시하는 API를 쓴다는 뜻도 아니다.

비휘발성은 무한 보존이나 장기 무관리 SSD 수준의 보존을 보장하지 않는다. 이 앱은 NAND와 HBF의 장기 리텐션 차이를 정량적으로 예측하지 않는다.

## 7. 시각화와 실행의 공통 규칙

3D 표면 색은 물질 구분용이고 신호 광점은 정보 흐름 표시다. 금속 안의 전자 궤적, 전기장 전파 속도 또는 개별 전자 수를 그린 것이 아니다. 분해 슬라이더는 물리 장치를 분해하는 동작이 아니라 구조를 보기 위한 도해 기능이다.

애니메이션 시간축은 단계별 교육 시간이다. NAND와 SRAM의 단계가 같은 재생 시간에 표시되어도 지연이 같다는 뜻이 아니다. 배속과 광점 이동 속도로 제품 성능을 측정할 수 없다.

종류·주소·입력을 바꾸면 미완료 연산은 시작 스냅샷으로 취소된다. 단계 되감기는 현재 연산의 시작 상태를 복사한 후 해당 단계까지 다시 실행하는 학습용 타임라인이다. 실제 장치가 물리 시간을 되돌리는 기능이 아니다.

읽기 출력은 감지 결과이고, 쓰기 출력은 모델 내부 검증 표시다. 실제 메모리 WRITE 명령이 쓰인 데이터를 외부 DQ로 자동 에코한다는 뜻이 아니다. PNG 내보내기는 캔버스만 포함하므로 HTML 구조 주석·설명 패널은 포함하지 않는다.

브라우저 새로고침 시 샘플 상태가 초기화된다. 비휘발성 실험은 앱의 전원 토글 안에서만 성립하며 localStorage·파일 영구 저장을 대신하지 않는다.
